# Reporting data coverage

The in-app Data coverage panel uses [the metric catalogue](../shared/integration-coverage.js) for the 13 reporting tabs. Published coverage is scoped per centre and date. A successful empty scope can yield zero occurrences. Unavailable metrics and uncovered scopes display as unavailable. Data from synthetic tests is not used in production.

| Reporting tab | Source-backed scope | Manual, pending or unavailable |
| --- | --- | --- |
| KPI Performance | ActivityHub distinct programme IDs and eligible dated session counts by recorded status, plus planned pax with coverage | Official targets and delivery attestations need confirmation. No completion workflow exists in ActivityHub. |
| Good Practices and Challenges | None | Staff submissions and evidence |
| Recent Developments | None | Meetings, feedback, developments and outcomes |
| Participant Profiles | Dated programme catalogue, domains, schedules and room capacities reported by ActivityHub | Dedicated programme capacity and available seats are absent. Attendance and demographics need other approved sources. |
| Health Data | None | Approved aggregate assessments and definitions needed. Individual records are restricted. |
| Fitness | Physical-domain schedules and recorded statuses | Outcomes, equipment and barriers form separate reporting measures. |
| H.ART | Sessions for explicitly approved Hub programme classifications | Scope and outcome definitions require confirmation. ActivityHub supplies no verified H.ART tags. |
| Media | None | Publicity integration or staff planning |
| Manpower | None | Approved aggregate leave tracker and manual staffing and volunteer planning |
| Training | None | Staff courses, outcomes, certification and costs |
| Logistics | None | Requests, costs and deadlines |
| Next Two Weeks | Future-start ActivityHub occurrences flagged as management highlights | Meetings, plans, risks and deadlines remain manual. |
| Next Three Months | Dated upcoming ActivityHub programme schedules and series | Milestones, dependencies and undated plans remain manual. |

Definitions are visible with each imported report. Planned pax reflects the source booking field. Room capacity reflects source venue settings; neither provides attendance, reach or available capacity. All records retain their source status, including past records still marked scheduled.
