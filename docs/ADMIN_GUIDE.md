# Administrator guide

Click **Workspace settings** in the top bar. Use Centres to create and maintain the centre registry. Deactivation keeps historical records visible and stops new reporting writes for that centre.

Use Periods to create named date ranges. The fortnight anchor in Organisation controls suggested dates. Organisation also configures the branding and financial year start month. The reporting period selector groups by the financial year of the period start.

Open Workspace settings to manage the shared organisation. Changes are attributed to the shared workspace.

Review Data sources for the integration inventory. Credentials are managed in backend deployment settings when individual adapters are introduced. See the [integration guide](INTEGRATION_GUIDE.md) for connection requirements.
