# Administrator guide

Open Account and settings → Workspace settings. Use Centres to create and maintain the centre registry. Deactivation keeps historical records visible and stops new reporting writes for that centre.

Use Periods to create named date ranges. The fortnight anchor in Organisation controls suggested dates. Organisation also configures the branding and financial year start month. The reporting period selector groups by the financial year of the period start.

Provision verified identities in Neon Auth. Use User access to add a reporting profile from the verified identity's unique user ID, choose the role, and set centre grants. HQ roles receive organisational centre access. Centre roles and restricted viewers receive their explicit grants. Deactivate a profile when access ends.

Review Data sources for the integration inventory. Credentials are managed in backend deployment settings when individual adapters are introduced. See the [integration guide](INTEGRATION_GUIDE.md) for connection requirements.
