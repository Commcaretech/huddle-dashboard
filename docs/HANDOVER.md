# Internship handover

- Confirm organisational owners and recovery contacts for Git, Vercel, Neon, source systems and document storage.
- Record deployment URL, Neon branch name, database role and secret locations in the organisation's approved system. Transfer ownership and revoke departing access.
- Back up via the approved Neon branch or a protected PostgreSQL dump. Rehearse restoration on a separate branch, checking organisation totals, scoped profiles, report entries and actions. Protect the backups with the same access controls as production.
- Re-run build, unit/API and browser checks after dependencies or schema change. Review the test-branch migration and test verified logins for each role.
- When adding fields, update shared module definitions, server validation and rendering together. New modules and utilities must preserve the 13 primary tabs unless management changes the specification.
- Review [development progress](DEVELOPMENT_PROGRESS.md) and [known limitations](KNOWN_LIMITATIONS.md). Confirm source contracts with data owners and track unresolved decisions in the organisation's project space.
