# Known limitations

- Analytical tabs show indicator labels and unavailable states. KPI definitions, goals, trend charts, matched health analysis, programme rankings, media analytics, and detailed staffing workflows are Phase 3.
- Excel and CSV import preview, mapping, templates, and migration of legacy SQLite records are pending.
- GlowBBDashboard manual integration is implemented and verified with synthetic fixtures. Hosted credentials, deployment checks and other source adapters are pending. There is no scheduler.
- Reporting approval, immutable meeting snapshots, management decisions, reports export and deterministic analytical insights are Phase 5. Current presentations use the live report selection.
- Training, procurement and planning offer manual record tracking. Calendar and roadmap are reporting views. Imported deadlines, attachments storage and additional approval automation are pending.
- Production Neon branch setup and Vercel deployment need real environment configuration and verification.
